# Deepraj Singh — Portfolio

Personal portfolio of **Deepraj Singh** — Full-Stack Developer (MERN) and Competitive Programmer (LeetCode Guardian, Codeforces Expert). Built with Next.js App Router, React 19, Tailwind CSS, Framer Motion, and TypeScript.

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org) (App Router)
- **Styling**: Tailwind CSS with custom terminal/hacker palette
- **Animations**: Framer Motion
- **Icons**: Lucide React & Devicons
- **Charts & Benchmarks**: Recharts
- **Live Data**: LeetCode GraphQL API, Codeforces API, CodeChef scraper, AtCoder integration

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
